#90 Days DSA Challenge (Python)

------Goal

This repository documents my journey of solving 90 Data Structures & Algorithms problems in 90 days using Python.

The goal is to build strong problem-solving skills and prepare for top tech companies.

------Approach

Instead of solving random questions, I follow a pattern-based learning approach:

1. Learn concept
2. Understand pattern
3. Solve 2–3 problems deeply
4. Maintain notes
5. Revise regularly
